Inspeção Estrutural por Robô PIG (Euler)

  • 🔍 Teorema de Euler: Todos os vértices da malha possuem grau par ⇒ Grafo conexo Euleriano.
  • ⚡ Algoritmo de Hierholzer (O(|E|)): Determina o circuito fechado visitando cada duto exatamente uma vez.
  • 🔄 Circuito Completo: BASE → DISP → HEX → XV-104 → TK-103 → SUP → TK-102 → XV-104 → TK-101 → SUP → BASE.
Cobertura 100% Determinística: Elimina sobreposição de trajeto e reduz o tempo de parada para manutenção periódica da estação.
